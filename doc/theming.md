# Theming & Localization

Design tokens, color schemes, OKLab standalone color derivation, typography,
metrics, easing curves, desktop settings, and localization.

## Key Types

* `AdwTheme` & `AdwThemeData` — Inherited theme configuration and lookup.
* `AdwColorScheme`, `AdwColors`, & `AdwAccentColor` — Libadwaita 1.10+ semantic
  tokens, 9 GNOME accent colors, high-contrast support, and CSS `color-mix` /
  OKLab helpers.
* `AdwStyleManager` & `AdwDesktopSettings` — Reactive light/dark, accent, and
  accessibility preference controllers.
* `AdwTypography`, `AdwMetrics`, & `AdwCurves` — Adwaita Sans/Mono type scale,
  spacing/radii constants, and reduced-motion-aware curves.
* `AdwLocalizations` — Built-in string localizations for Adwaita widgets.
