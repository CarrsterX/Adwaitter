# Display

Visual feedback and data display widgets: avatars, emblems, spinners, progress
bars, and level bars.

## Key Widgets

* `AdwAvatar` — Circular user/entity avatar with generated initials and
  official GNOME color palette.
* `AdwSpinner` — Smooth indeterminate loading indicator.
* `AdwProgressBar` & `AdwLevelBar` — Determinate/indeterminate progress and
  segmented level indicators.
* `AdwEmblem` — Geometric Libadwaita vector emblem.
