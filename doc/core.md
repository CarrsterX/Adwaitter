# Core

Low-level framework primitives powering Adwaita scrolling, spring physics, and
text selection without depending on `material.dart`.

## Key Types

* `AdwScrollBehavior` & `AdwScrollbar` — GNOME-styled overlay scrollbars and
  cross-platform scroll physics.
* `AdwSpringParams` & `AdwSpringSimulation` — Libadwaita spring animation
  physics (`dampingRatio`, `mass`, `stiffness`).
* `AdwSelectableRegion` & `AdwTextSelectionControls` — Pure-Flutter text
  selection toolbar and OSD magnifier.
